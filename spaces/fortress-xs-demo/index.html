A small classifier for prompt injection and harmful requests, the model inside Mobius Guard. It runs in your browser: your text never leaves this page. Model card for numbers and limits.

Thresholds are the model's own: each is set so that 1% of ordinary user messages go over it. Mobius Guard blocks over the attack threshold and only logs over the harmful one, unless told to block. Text over 512 tokens is cut, as in the model. Scores can differ slightly from the server runtime (both INT8).
